Este projeto é uma aplicação web feita para praticar o consumo assíncrono de APIs e a manipulação do DOM com JavaScript. Utilizando a função nativa fetch, a aplicação faz requisições à API do TVmaze com base no termo digitado pelo usuário em um formulário de busca. Após converter a resposta para JSON , o JavaScript limpa a tela e usa createElement e appendChild para renderizar os resultados dinamicamente em cards responsivos (CSS Grid). Cada card exibe o nome, a imagem de capa e o score da série. O código também conta com tratamento de erros via try/catch , validação de campos vazios, feedback de carregamento (loading) e mensagens amigáveis para buscas sem resultado.
