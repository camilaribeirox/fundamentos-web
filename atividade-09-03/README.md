# Atividade: Portfólio Simples com HTML e CSS
Esta atividade consistiu no desenvolvimento de um portfólio pessoal utilizando HTML5 e CSS3 de forma modular. O foco técnico foi a organização de uma estrutura semântica composta por cabeçalho, sobre, habilidades e projetos, integrada a uma folha de estilo externa. 
Foram aplicados recursos específicos de CSS, como a estilização de letra capitular com ::first-letter, a diferenciação de itens de lista via :nth-child e a criação de efeitos interativos de hover nos cards de projetos, garantindo um layout organizado e funcional.
